# Manchester United 2025/26 Performance Dashboard — Java (v3.2)

An **unofficial Java 17+ desktop project** that explores Manchester United's **2025/26 Premier League season**. This repository is intended for learning, not as a product affiliated with the football club.


## What you can do
This is a dashboard outlining Manchester United's statistics for the 25/26 Premier League season. It features insights into team performance, individual player statistics, and a user-friendly interface.

 Quick start - Windows and IntelliJ

1. Extract the project ZIP.
2. In IntelliJ IDEA select **File → Open**, choose the extracted folder and set the **Project SDK to Java 17 or newer**.
3. Open `src/ManchesterUnitedDashboard.java` and run `main()`.
4. Alternatively double-click **`run-windows.bat`** (requires the JDK on your PATH) or run `java -jar ManchesterUnitedDashboard.jar`.

if there is an error, click 'modify run configuration' in the terminal, the 'Working Directory' should be set to '...\man united tracker 2526\manchester-united-java-dashboard-v3.2'
